IBM Bob 2.0 Hackathon

How Prove Me Wrong works

Read it as a script

  1. 1
    HireTypes a guess

    Free text, about a real behavior in a real codebase, here axios/axios.

  2. 2
    AppRelays it to Bob

    Along with which of the 8 pre-planned topics this question belongs to.

  3. 3
    BobReads the real source

    Not training knowledge, the actual current file, for that specific topic.

  4. 4
    BobJudges the guess and writes the citation

    Right, wrong, or partial, plus the exact file and line that proves it.

  5. 5
    AppShows the correction

    The hire sees Bob's verdict and can click the citation to open the real GitHub line.
